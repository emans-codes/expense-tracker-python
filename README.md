# Expense Tracker

A simple command-line Expense Tracker built with Python. This project allows users to manage their expenses through an interactive menu.

# Features
Add new expenses
View all recorded expenses
Calculate total expenses
Edit existing expenses
Delete expenses
Validate user input
Handle invalid numerical input using exception handling
Interactive menu-driven interface
# Technologies Used
Python 3
Lists
Functions
Loops
Conditional Statements
try/except
enumerate()
User Input Handling
# How It Works

The program provides a menu with six options:

Add Expense — Add an expense name and amount.
View Expenses — Display all recorded expenses.
Calculate Total — Calculate the total amount of all expenses.
Exit — Close the application.
Delete Expense — Remove an expense by its number.
Edit Expense — Update an existing expense.
# Getting Started
Prerequisites

Make sure Python 3 is installed on your computer.

# Run the Project

Clone the repository:

git clone https://github.com/emans-codes/expense-tracker-python.git

Navigate to the project folder:

cd expense-tracker-python

Run the program:

python expense_tracker.py
